# 小纹理平铺扰动特效 (Small Texture Tiling Distortion)

## 原理

使用**极小尺寸（如 4×4）的随机纹理**，通过**大幅平铺 + 双线性插值**，产生低频、平滑、有机的屏幕空间扰动。

核心机制：
- 小纹理（4×4）→ 每个纹素覆盖屏幕大片区域（如 120 像素）
- 双线性插值 → 相邻纹素之间产生平滑渐变
- 大幅平铺（如 `4.0f * UV`）→ 产生规则但不重复的斑块图案

## 与 SSAO 随机纹理的对比

| | 标准 SSAO（高频噪声） | 本特效（低频扰动） |
|:--:|:--------------------:|:-----------------:|
| 纹理尺寸 | 256×256 | 4×4 ~ 16×16 |
| 平铺倍数 | 4× | 4× ~ 8× |
| 每纹素覆盖 | ~2 像素 | 30~120 像素 |
| 采样方式 | 点采样或线性 | **线性（关键）** |
| 视觉效果 | 颗粒噪点 | **水纹/流动/扭曲** |

## 应用场景

这是 **屏幕空间扭曲（Screen Space Distortion）** 的核心技术之一，适用于：

### 1. 热浪 / 高温扭曲
- 用扰动值偏移场景 UV，产生空气受热折射的效果
- 随时间更新偏移量可产生流动感

### 2. 水面 / 液体表面
- 扭曲背景的反射/折射，配合法线贴图更真实
- 低成本水面效果

### 3. 魔法/能量场
- 屏幕空间的有机扭曲，模拟能量场对光线的干扰
- 结合透明度可得能量护盾效果

### 4. 毒液 / 腐蚀效果
- 低频蠕动扭曲，模拟腐蚀性液体对画面的侵蚀
- 叠加颜色校正增强视觉冲击

### 5. 梦境 / 眩晕效果
- 全屏缓慢扭曲，模拟醉酒、幻觉或梦境切换
- 配合时间变量产生呼吸感

## 核心实现思路

```hlsl
// 采样小纹理扰动值
float2 distortion = gSmallNoiseMap.SampleLevel(gsamLinearWrap, uv * 4.0f, 0.0f).rg;
// 映射到 [-1, 1] 范围
distortion = distortion * 2.0f - 1.0f;
// 用扰动值偏移场景 UV
float2 distortedUV = uv + distortion * gIntensity;
// 采样场景颜色
float4 color = gSceneColor.Sample(gsamLinearClamp, distortedUV);
```

## 优势

- **极低成本** — 4×4 纹理只有 16 个纹素，几乎不占显存
- **天然平滑** — 线性插值自动产生有机过渡，无需额外模糊
- **难以预测** — 微小纹理 + 随机数据 + 平铺组合产生复杂图案
- **易于动画** — 随时间偏移 UV 即可产生流动感

## 来源

此效果源自 SSAO 实现中对 4×4 随机纹理的错误使用（低频水波纹），后经分析发现是屏幕空间扭曲特效的核心方法。
